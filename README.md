# chocolate-analyzer-project
This small site analyzes your chocolate name, and give data to you with a small twist 

## Feature 
1. Give data about your chocolate.
2. You can get to know the cocoa percentage in your entered chocolate, which is kinda important point
3. You can get which country that chocolate belongs to.
4. You can get to know that which company it belongs to.
5. New updates gonna come for this project...

 ## Tech Stack
 1. HTML5: For skeleton and basic design.
 2. CSS3: For beauty and looks modern instead of clutter.
 3. Vanilla JS: To get responses and special twist smoothly
 4. JSON (file or storage): To store the data of chocolates, to get data safely from there, it's like godown.
